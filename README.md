# Simple To‑Do List App

A minimal, modern web application that lets you manage tasks locally in your browser. The app provides a clean, professional UI with smooth animations, rounded elements, and subtle shadows. All data is persisted using `localStorage`, so your list is saved between sessions without any server.

## Features
- **Add tasks** – type a task description and press *Add*.
- **Edit tasks** – click the pencil icon to modify a task.
- **Delete tasks** – remove a task with a single click.
- **Mark as completed** – click a task to toggle its completed state; completed tasks are displayed with a distinct style.
- **Responsive design** – works on mobile, tablet, and desktop screens.
- **Local persistence** – tasks are saved in the browser’s `localStorage`.

## Getting Started
1. Clone the repository or download the files.
2. Open `index.html` in a web browser.
3. Start adding, editing, and completing tasks.

No build step or server is required – the app is pure HTML, CSS, and JavaScript.

## Project Structure
- `index.html` – the main HTML page.
- `style.css` – styling for a soft, rounded, minimal UI.
- `script.js` – JavaScript that handles task CRUD operations and persistence.
